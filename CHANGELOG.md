# Changelog

## 0.2.0

- Studio clock: optional `timer.*` entity, which takes over while it runs and counts up for a
  minute when it ends.
- Studio clock: picture shifts a few pixels every three minutes (`burn_in_shift`).
- Studio clock: the weekday-and-time label for a distant event fits inside the ring.
- Studio clock: `height` option.

## 0.1.0

- Studio clock card: ring of dots, time, countdown to the next calendar event, film leader,
  compact and wide layouts, visual editor.
